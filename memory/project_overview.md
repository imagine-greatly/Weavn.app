weavn.app is a SaaS website conversion intelligence platform. Core product: paste a URL, get 308 automated checks, ranked findings, rewritten copy, dimension scores — results in ~90 seconds.

**Why:** Building a public REST API on top of the existing scanning engine to unlock agency and developer plans.

**Three dashboard personas:**
- **Founder** (`/dashboard/founder`) — personal diagnostic instrument. One site, one score, ranked findings. Lab report UX.
- **Agency** (`/dashboard`) — multi-client command center. Sidebar client list sorted worst-first. Portfolio grid + client detail view.
- **Developer** (`/dashboard/developer`) — API infrastructure control panel. Key management, usage bar, scan request log, webhooks, quick reference CodeBlocks.

**How to apply:** When suggesting features or copy, consider which persona is the target. Founders want "what to fix today." Agencies want "which client needs attention." Developers want "is my key working and how much quota do I have."
